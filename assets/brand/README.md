# EvolveMemory visual assets

This project shares the 7SAO penguin mascot with the other repositories in the portfolio. Project identity is expressed by its own symbol, accent color (`#EFA3C3`), and factual product copy.

| File | Role and consumer |
| --- | --- |
| `penguin.png` | Transparent mascot export for this project; used inside the hero source. |
| `project-mark.svg` | Small vector project identifier; paired with the shared mascot. |
| `../readme-banner.svg` | Editable, self-contained hero source. The mascot is embedded so the source renders without remote image dependencies. |
| `../readme-banner.png` | 1600 × 600 GitHub README export, shared by both language editions. |

## Source and maintenance

The owner supplied the character reference. The 2026-11-16 mascot illustration was generated with the built-in image generation tool using that reference, then exported at a smaller size for repository use. The new seated-computer pose replaces the earlier waving mascot. It is an illustration, not a product screenshot or an execution result.

Keep the gray/cream character, mint scarf, snowflake, and soft hand-drawn texture consistent. Use the project's accent for the surrounding interface and symbol rather than recoloring the character. Keep substantial copy in selectable Markdown and limit banner text to the project name, purpose, and three capabilities.

Edit the SVG source and re-export the PNG together. Verify the result at README width and at a narrow mobile width; keep the asset paths stable. Do not add measured-result badges to the artwork.
